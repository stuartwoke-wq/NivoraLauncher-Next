# Nivora Launcher

A privacy-first, offline-first Android launcher built with Kotlin and
Jetpack Compose.

## Project identity

- Application ID: `org.nivora.launcher`
- Kotlin namespace: `org.nivora.launcher`
- Minimum Android version: Android 13 (API 33)
- UI: Jetpack Compose and Material 3

## Status

Milestone 1: clean application foundation in progress.

The current screen is a foundation placeholder. App discovery, persistent
workspace, dock, folders, widgets, search, and customization are not yet
implemented.

## Build

Use JDK 17 and the Gradle version configured for this project. Android SDK
platform 36 and the corresponding build tools are required.

The CI workflow is intended to build the debug APK in GitHub Actions.
